## Learned in this session
- Check runs: one at a time on this machine; parallel runs cause 'access denied' (MoveFileEx under Defender) and timing failures.
- Agents with very large contexts stall (stream watchdog); start a fresh agent per follow-up instead of resuming a 300k-token one.
- Fakes hide dead real adapters (#33 N1): every real adapter needs one harmless read in a check.
- Usage limits stop all agents; resume each with "continue where you stopped, check git status first".
